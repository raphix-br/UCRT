# UCRT Firmware

Diretório reservado para o firmware do UCRT.

Ainda não há MCU definitivo.

O firmware deverá futuramente incluir:
- vídeo;
- sincronismo;
- OSD;
- geometria;
- configuração do CRT Profile;
- armazenamento de parâmetros;
- diagnóstico;
- comunicação entre módulos;
- padrões de teste.

A escolha do MCU ocorrerá depois da definição dos requisitos de vídeo e sincronismo.
